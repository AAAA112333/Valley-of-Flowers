## 🚀 النشر على GitHub Pages (3 دقائق)

1. اعمل حساب على https://github.com
2. اضغط **New repository** وسمّه `flower-shop` وخلّيه **Public**
3. ارفع الملفات: **Add file > Upload files** واسحب `index.html` + `.nojekyll`
4. اضغط **Commit changes**
5. روح **Settings > Pages** واختار:
   - Source: **Deploy from a branch**
   - Branch: **main** / **root** ثم **Save**
6. بعد دقيقة هيظهر لينك موقعك: `https://USERNAME.github.io/flower-shop`

## ⚡ النشر على Netlify (أسرع)

1. ادخل https://app.netlify.com/drop
2. اسحب فولدر `flower-shop` كله في الصفحة
3. استلم اللينك فوراً وغيّر اسمه من Site settings
